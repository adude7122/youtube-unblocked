Enter your YouTube API Key

ViewTube is a YouTube frontend powered by the official YouTube Data API v3. Get a free API key from Google to get started.

1. Go to console.cloud.google.com
2. Create a project → APIs & Services → Enable APIs
3. Search and enable YouTube Data API v3
4. Go to Credentials → Create API Key
5. Paste it below and hit Go
